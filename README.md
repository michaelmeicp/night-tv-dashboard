# 澳門夜間看板

繁體中文、低眩光的公開靜態儀表板，適合 16:9 電視，並提供可捲動的手機版。

- 澳門時區時鐘與通用月曆。
- 天氣、金融行情與中文新聞為有日期及來源的快照；重新載入不會更新資料。
- 未核實的汽油／柴油牌價及其他報價顯示缺口。
- 新聞可暫停；偏好減少動態時停止自動滾動，可手動左右捲動。
- 每區的「⋯ → View data source → Data preview」可查看來源、資料時間及限制。

不包含私人行事曆、待辦、健康資料、帳戶、投資持倉或本機私人資料匯入功能。公開股票與基金資訊不代表任何人的持倉或選擇。

`index.html` 為自包含頁面，`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案。無後端、環境變數、登入或自動更新排程。

本機預覽：`python3 -m http.server 8765 --bind 127.0.0.1`，然後開啟 `http://127.0.0.1:8765/`。
