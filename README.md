# 澳門夜間看板

繁體中文、低眩光的公開靜態儀表板，適合 16:9 電視，並提供可捲動的手機版。

- 澳門時區時鐘與通用月曆。
- 睡眠模式預設頁面亮度 55%，可在 20–85% 間調節；不改動電視或作業系統設定。
- 12 組真實歷史走勢，標示實際期間、單位及首末樣本變動。每圖獨立縮放；股票價格變動不含股息。
- 月曆縮小置頂，中文新聞放大並慢速滾動。
- 天氣、金融行情與中文新聞為有日期及來源的快照。觀測時間、成功擷取時間及建置時間分開記錄。
- 逐來源顯示更新失敗、保留舊值及過期狀態；失敗不重設資料時間、不補零或假曲線。
- 開頁每五分鐘檢查同站的已發布資料版本，有新版時可按鈕載入。檢查失敗會退避；401／403／451 會停止檢查。這不是即時行情或外部 API 自動刷新。
- 未核實的汽油／柴油牌價及其他報價顯示缺口。
- 新聞可暫停；偏好減少動態時停止自動滾動，可手動左右捲動。
- 每區的「⋯ → View data source → Data preview」可查看來源、資料時間及限制。

不包含私人行事曆、待辦、健康資料、帳戶、投資持倉或本機私人資料匯入功能。公開股票與基金資訊不代表任何人的持倉或選擇。

`index.html` 為自包含頁面，`.nojekyll` 讓 GitHub Pages 直接提供靜態檔案。`data-version.json` 只提供已發布快照的雜湊與建置時間。無後端、環境變數、登入、憑證或自動更新排程。

一次性更新原專案資料（Python 3.9+，僅標準函式庫）：

```sh
python3 scripts/refresh_public_data.py --check
python3 scripts/refresh_public_data.py
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/refresh-state.test.cjs
```

工具擷取 CoinGecko BTC／BNB 報價及30日觀測、Frankfurter v1 USD/HKD 每日參考值、Frankfurter／AMCM USD/MOP 每日參考值，以及 SMG 官方整點觀測與逐日預報。嚴格驗證數值、單位、幣種及日期，再重建嵌入的 reviewed snapshot 與版本檔。錯誤來源保留最後有效資料和原時間，記錄此次失敗；其他來源可獨立成功。沒有重試被拒絕的 API，也沒有備援代理。

每次執行只更新本機檔案，須檢查結果、提交並發布後，公開頁才有新資料。現有 Data runtime 的 GitHub Pages 版本沒有支援的瀏覽器觀測列寫入介面；工具不修改 runtime 或 reviewed-row 保護。股票、基金、指數及指定原油合約仍保留原先已核實快照，沒有宣稱已持續刷新。新聞也保留原資料日期。原油指定合約、澳門油價與除牌標的的歷史缺口不以假線或零價代替。

過期門檻：加密貨幣報價30分鐘、SMG觀測2小時、每日匯率4日（容許週末）；判斷採來源觀測時間，並隨頁面時鐘變化。過了澳門午夜，不把舊日預報稱為今日預報。來源檢查與新版本比較失敗均不自動重新載入頁面。

天氣來源：[澳門氣象局 XML](https://xml.smg.gov.mo/)、[政府開放資料目錄](https://data.gov.mo/Detail?id=070f7d9b-f734-4269-841c-0859912a5b15)。價格與歷史來源連結保存在每列 `source_url`，可從頁面資料來源檢視器查看。

本機預覽：`python3 -m http.server 8765 --bind 127.0.0.1`，然後開啟 `http://127.0.0.1:8765/`。
